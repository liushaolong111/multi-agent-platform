flowchart TD
    subgraph OFFLINE["一、数据准备（离线，手动执行）"]
        direction TB
        CSV["data/*.csv

        MD["data/*.md
（制度文档）"]
        ERP0[("外部 ERP 系统
采购订单 · 库存余额 · 到货计划")]
        CSV --> ENTITY["entity/ 领域实体（Pydantic，脱离 ORM）"]
        ENTITY --> MAPPERL["mapper/ 转换器
Entity ↔ ORM Model"]
        ERP0 -->|"MCP：erp_fetch_*（可选数据源）"| MAPPERL
        MAPPERL --> SEED["seed_business_db.py
灌库 + 演示账号 · Redis 分布式锁保护"]
        SEED --> MYSQL[(MySQL 业务库
projects / cost_records / safety_issues / material_records / users)]
        MD --> INGEST["ingest.py
切块 + bge 向量化"]
        INGEST --> FAISS[(FAISS 向量库
知识文档片段)]
        MYSQL --> SYNC["sync_business_to_rag.py
聚合生成业务摘要"]
        SYNC --> SYNCMD["sync_*.md
（company 可见性）"]
        SYNCMD --> REBUILD["重建向量索引"]
        REBUILD --> FAISS
    end

            RETRIEVE["多路召回 multi_route_search
